# learning-log — 运维开发转型学习仓库

> 从网管到「能写工具自动化掉重复运维工作的人」。
> 计划起点：2026-11-11 ｜ 阶段一：Linux + Python（0-2 月）

## 目录约定

```
learning-log/
├── README.md          ← 本文件（每周末更新一段学习笔记）
├── week01/            ← 每周一个文件夹，放当周练习和作品
│   └── hello.py
├── notes/             ← 学习笔记（3 行也行，写了就算数）
└── scripts/           ← 站得住的实用脚本，慢慢攒成作品集
```

## 每周节奏

- 工作日：每天 45-60 分钟（教程 + 小练习）
- 周末：2-3 小时整块（做当周作品）
- 每周末：`git commit` + 在 README 写 3 行本周笔记
